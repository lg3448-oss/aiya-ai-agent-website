# Website fonts

Bricolage Grotesque for expressive display headings and Instrument Sans for body text. Both are self-hosted Latin variable subsets in WOFF2 format. Original files come from the official google/fonts repository:

- https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque
- https://github.com/google/fonts/tree/main/ofl/instrumentsans

The earlier Manrope and DM Sans assets remain available for prior versions:

- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/dmsans

The accompanying OFL files contain the copyright and SIL Open Font License terms. No external font request is needed at runtime. Source TTF files are preserved locally in output/fonts.
