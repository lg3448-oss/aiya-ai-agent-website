# App logo array

The tools chapter uses a centred, frameless array of 28 local SVG marks. Buttons retain their accessible names, example selection state and count. Pointer hover or keyboard focus enlarges just the logo to 1.08 over 180ms and reveals the name. The button hit area stays still. Touch layouts avoid sticky hover transforms; reduced-motion preferences disable transitions.

The contact-orbit logo hover uses the same 1.08 scale for consistency. The page describes an example stack; it does not claim a number of working integrations.

Sixteen new SVGs were downloaded on 2026-11-09 from the Simple Icons project, using `https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/{slug}.svg`. Fill colours were applied locally. Slugs: gmail, googlesheets, googledrive, googlecalendar, notion, hubspot, shopify, zapier, stripe, airtable, github, whatsapp, telegram, zendesk, asana, trello. The prior twelve marks are unchanged.

Source project and icon usage information: https://github.com/simple-icons/simple-icons. Assets are served locally; the live page does not request icons from an external CDN.
