# Site directory and workflow ideas

All three pages share a full dark-navy footer with brand, social/contact links, services, resources and nine workflow links. Every service/resource destination exists. The homepage footer is its own eighth chapter so the contact constellation keeps its full-screen layout. Subpages use a natural-scrolling footer.

The updates entry opens a prewritten email request to the team, as chosen by the owner. It does not claim to add an address to a mailing list. No subscription database or email platform is connected.

`use-cases.html` describes nine workflow ideas across marketing/content, research/insight and everyday operations. Each explains its inputs and reviewable output, with an email discussion link. These are scoped ideas rather than claims of already-deployed customer workflows. The new Use cases navigation entry appears on all three pages.

The footer is static HTML so it remains useful without JavaScript; keep its markup aligned across `index.html`, `faq.html` and `use-cases.html`. Styles are in `site-footer.css`. Browser checks verify all footer page/fragment destinations, the email request, case count and responsive layout.
